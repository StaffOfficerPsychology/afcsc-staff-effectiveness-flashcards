AFCSC SENIOR COURSE 48 – SECOND STAFF EFFECTIVENESS FLASHCARD SERIES

This independent PWA contains 180 revision items:
- Phase 1: 60 Multiple-Choice Questions
- Phase 2: 60 True/False Questions (30 true and 30 false)
- Phase 3: 60 Fill-in-the-Gap Questions

The question statements are based on the uploaded AFCSC lecture materials available for this series.
The app supports phase selection, topic filtering, answer reveal, explanations, shuffle,
previous/next navigation, locally saved progress and offline use after the first successful load.

This is a separate application package. It does not replace the earlier Psychology flashcard deck
or the existing AFCSC Psychology Quiz application.

Review note: The MCQ options use other lecture-grounded statements as distractors. Review the
question bank against the original slide decks before formal examination use, particularly where
a lecturer's wording or a slide-specific example is required.

To use: open index.html locally, or deploy the folder to a static web host for PWA installation.
